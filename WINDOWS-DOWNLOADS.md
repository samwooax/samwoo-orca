# SAMWOO-ORCA Windows downloads

Official Windows installers are published on the
[GitHub Releases page](https://github.com/samwooax/samwoo-orca/releases).

SAMWOO-ORCA uses SignPath.io for Windows code signing, with certificates issued by the
[SignPath Foundation](https://signpath.org). Do not install unsigned workflow artifacts;
only administrator-approved, published releases are intended for installation or updates.
